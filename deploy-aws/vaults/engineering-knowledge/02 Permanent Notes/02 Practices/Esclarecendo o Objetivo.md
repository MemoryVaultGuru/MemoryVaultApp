Esta atividade tem como propósito fazer com que cada membro da equipe compartilhe seu entendimento sobre os objetivos de negócio do produto. Através da discussão de diferentes pontos de vista, o grupo busca alcançar um **consenso** sobre o que é realmente prioritário para o sucesso do projeto.

## A Pergunta de Ouro
Para guiar a reflexão, o facilitador utiliza a seguinte indagação:

> "Se você tiver que resumir o produto em três objetivos para o negócio, quais seriam eles?"

## Passo a Passo da Atividade

1. **Levantamento Individual**: Cada participante escreve, individualmente, três respostas para a pergunta acima.
2. **Compartilhamento e Agrupamento**: Os participantes colocam suas respostas em um canvas comum, agrupando os post-its por similaridade (afinidade).
3. **Escrita Coletiva**: O time trabalha junto para reescrever os objetivos de forma clara e homogênea.
4. **Descarte e Foco**: Durante a discussão, elementos que não são realmente objetivos do produto devem ser descartados para que o foco nítido do projeto apareça.

## Exemplo Prático (Easy-bola)

No exemplo do aplicativo para peladeiros, a atividade resultou em três objetivos principais:

- Encontrar partidas.
- Divulgação.
- Opções de partidas.
